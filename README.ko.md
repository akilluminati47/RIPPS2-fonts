# RIPPS2 Sleek

[![License OFL](https://img.shields.io/badge/license-OFL--1.1-orange?style=flat-square)](LICENSE-OFL)
[![License MIT](https://img.shields.io/badge/tools-MIT-green?style=flat-square)](LICENSE-MIT)
[![Releases](https://img.shields.io/github/v/release/akilluminati47/RIPPS2-fonts?style=flat-square)](https://github.com/akilluminati47/RIPPS2-fonts/releases)
[![RIPPS2](https://img.shields.io/badge/made_for-RIPPS2-3c6ef0?style=flat-square)](https://github.com/akilluminati47/RIPPS2)

PS2 프런트엔드 [RIPPS2](https://github.com/akilluminati47/RIPPS2)를 위해 그린 서체입니다. 메뉴, 버튼 힌트, 설정, 각 목록의 이름이 되는 보기 단어, 그리고 RIPPS2와 어울리고 싶은 모든 테마에 쓰입니다.

글자는 PS2 로고의 레터링을 본보기로 삼았습니다. 가늘고 고른 한 획, 각진 모서리, 격자 위의 가로·세로 막대로 짠 글자, 그리고 로고 자체의 열린 형태(볼 위에 기둥이 없는 P, 지그재그 2). 폭이 좁아 버튼 힌트 한 줄 전체가 640픽셀 화면에 들어갑니다.

| 컷 | 굵기 | 대소문자 | RIPPS2에서 |
|---|---|---|---|
| **Regular** | 가는 획 | 대문자(소문자도 대문자로 그림) | 힌트, 메뉴, 설정, 소스 이름 |
| **Bold** | 굵은 획 | 대문자 | 큰 글리프 옆의 라벨, 보기 단어, 릴리스 줄 |
| **Bold Case** | 굵은 획 | 진짜 소문자 | 입력한 글, 화면 키보드, 설명 |

<a id="use"></a>

## 사용법

**RIPPS2 테마에서는** 글꼴이 이미 `RIPPS2.elf` 안에 있습니다. 이름만 지정하고 아무것도 함께 보내지 않아도 됩니다:

```
default_font=builtin:ripps2sleek       # Regular
font3=builtin:ripps2sleekbold          # Bold
font1=builtin:ripps2sleekcase          # Bold Case
```

[RIPgrid](https://github.com/akilluminati47/RIPPS2-themes)는 전부 이 서체로 짜여 있습니다. OPL 계열의 다른 테마도 자기 폴더의 TTF를 여느 글꼴처럼 쓸 수 있습니다.

**웹에서:**

```css
@font-face { font-family: "RIPPS2 Sleek"; font-weight: 400; src: url("RIPPS2Sleek-Regular.woff2") format("woff2"); }
@font-face { font-family: "RIPPS2 Sleek"; font-weight: 700; src: url("RIPPS2Sleek-Bold.woff2") format("woff2"); }
@font-face { font-family: "RIPPS2 Sleek Case"; font-weight: 700; src: url("RIPPS2Sleek-BoldCase.woff2") format("woff2"); }
```

**PC에서:** 평소처럼 TTF를 설치합니다. Regular와 Bold는 한 패밀리 *RIPPS2 Sleek*, Bold Case는 별도 패밀리 *RIPPS2 Sleek Case*(Bold)라서 서로 부딪히지 않습니다.

<a id="build"></a>

## 빌드

모든 글리프는 높이 6단위(대문자 높이) 격자 위의 꺾은선 묶음이며, 각각 획을 입힌 뒤 하나의 깔끔한 윤곽으로 합칩니다. 그림은 [tools/make_sleek_font.py](tools/make_sleek_font.py)(RIPPS2가 자기 사본을 만드는 바로 그 파일)에 있고, [tools/build.py](tools/build.py)가 여기 있는 모든 것을 그것으로 만들고 데스크톱 앱과 브라우저가 읽는 이름과 굵기를 글꼴에 붙입니다(RIPPS2 자체는 윤곽만 읽습니다).

```
pip install -r requirements.txt
python tools/build.py
```
