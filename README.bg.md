# RIPPS2 Sleek

[![License OFL](https://img.shields.io/badge/license-OFL--1.1-orange?style=flat-square)](LICENSE-OFL)
[![License MIT](https://img.shields.io/badge/tools-MIT-green?style=flat-square)](LICENSE-MIT)
[![Releases](https://img.shields.io/github/v/release/akilluminati47/RIPPS2-fonts?style=flat-square)](https://github.com/akilluminati47/RIPPS2-fonts/releases)
[![RIPPS2](https://img.shields.io/badge/made_for-RIPPS2-3c6ef0?style=flat-square)](https://github.com/akilluminati47/RIPPS2)

Шрифтът, начертан за [RIPPS2](https://github.com/akilluminati47/RIPPS2), фронтенда за PS2: неговите менюта, подсказки за бутони, настройки, думата на изгледа, която назовава всеки списък, и всяка тема, която иска да изглежда като своя.

Буквите следват надписа от логото на PS2: една тънка, равномерна линия, квадратни ъгли, букви от хоризонтални и вертикални щрихи върху мрежа и отворените форми на самото лого (P без стебло над коремчето, зигзагообразното 2). Те са тесни, така че цял ред подсказки за бутони се побира на екран от 640 пиксела.

| Начертание | Дебелина | Регистър | В RIPPS2 |
|---|---|---|---|
| **Regular** | тънка линия | главни букви (малките се изписват като главни) | подсказки, менюта, настройки, името на източника |
| **Bold** | дебела линия | главни букви | етикети до големи глифове, думата на изгледа, реда на версията |
| **Bold Case** | дебела линия | истински малки букви | въведен текст, екранната клавиатура, описания |

## Набор от знаци

Основна латиница, Latin-1 и Разширена латиница A/B: 337 кодови точки във всяко начертание. Засега буквите с ударения се изписват като основната си буква. Пълният списък: [docs/charset.md](docs/charset.md).

<a id="use"></a>

## Употреба

**В тема на RIPPS2** шрифтовете вече са вътре в `RIPPS2.elf`; посочете ги и не прилагайте нищо:

```
default_font=builtin:ripps2sleek       # Regular
font3=builtin:ripps2sleekbold          # Bold
font1=builtin:ripps2sleekcase          # Bold Case
```

[RIPgrid](https://github.com/akilluminati47/RIPPS2-themes) е изцяло набран с тях. Всяка друга тема от семейството на OPL може да ползва TTF файловете от собствената си папка като всеки шрифт.

**В уеб:**

```css
@font-face { font-family: "RIPPS2 Sleek"; font-weight: 400; src: url("RIPPS2Sleek-Regular.woff2") format("woff2"); }
@font-face { font-family: "RIPPS2 Sleek"; font-weight: 700; src: url("RIPPS2Sleek-Bold.woff2") format("woff2"); }
@font-face { font-family: "RIPPS2 Sleek Case"; font-weight: 700; src: url("RIPPS2Sleek-BoldCase.woff2") format("woff2"); }
```

**На компютър:** инсталирайте TTF файловете както обикновено. Regular и Bold са едно семейство, *RIPPS2 Sleek*; Bold Case е отделно семейство, *RIPPS2 Sleek Case* (Bold), така че двете никога не се сблъскват.

<a id="build"></a>

## Изграждане

Всеки глиф е набор от начупени линии върху мрежа, висока шест единици (височината на главните букви); всяка получава щрих и щрихите се сливат в един чист контур. Рисунката е в [tools/make_sleek_font.py](tools/make_sleek_font.py) (същия файл, от който RIPPS2 изгражда своите копия); [tools/build.py](tools/build.py) прави всичко тук от него и дава на шрифтовете имената и дебелините, които четат настолните програми и браузърите (самият RIPPS2 чете само контурите).

```
pip install -r requirements.txt
python tools/build.py
```
