# RIPPS2 Sleek

[![License OFL](https://img.shields.io/badge/license-OFL--1.1-orange?style=flat-square)](LICENSE-OFL)
[![License MIT](https://img.shields.io/badge/tools-MIT-green?style=flat-square)](LICENSE-MIT)
[![Releases](https://img.shields.io/github/v/release/akilluminati47/RIPPS2-fonts?style=flat-square)](https://github.com/akilluminati47/RIPPS2-fonts/releases)
[![RIPPS2](https://img.shields.io/badge/made_for-RIPPS2-3c6ef0?style=flat-square)](https://github.com/akilluminati47/RIPPS2)

قلمی که برای [RIPPS2](https://github.com/akilluminati47/RIPPS2)، فرانت‌اند PS2، کشیده شده: منوهایش، راهنمای دکمه‌ها، تنظیمات، واژهٔ نمایش که نام هر فهرست است، و هر پوسته‌ای که بخواهد خودی به نظر برسد.

حروف از نوشتهٔ لوگوی PS2 الگو می‌گیرند: یک خط نازک و یکنواخت، گوشه‌های چهارگوش، حروفی ساخته از میله‌های افقی و عمودی روی یک شبکه، و شکل‌های باز خود لوگو (P بی‌ساقه بالای شکمش، ۲ زیگزاگی). باریک‌اند، پس یک ردیف کامل راهنمای دکمه‌ها در صفحه‌ای ۶۴۰ پیکسلی جا می‌شود.

| برش | ضخامت | حالت حروف | در RIPPS2 |
|---|---|---|---|
| **Regular** | خط نازک | حروف بزرگ (کوچک‌ها بزرگ کشیده می‌شوند) | راهنماها، منوها، تنظیمات، نام منبع |
| **Bold** | خط ضخیم | حروف بزرگ | برچسب‌های کنار نشانه‌های بزرگ، واژهٔ نمایش، سطر نسخه |
| **Bold Case** | خط ضخیم | حروف کوچک واقعی | متن تایپ‌شده، صفحه‌کلید روی صفحه، توضیحات |

## استفاده

**در یک پوستهٔ RIPPS2** قلم‌ها از قبل درون `RIPPS2.elf` هستند؛ نامشان را بیاورید و چیزی نفرستید:

```
default_font=builtin:ripps2sleek       # Regular
font3=builtin:ripps2sleekbold          # Bold
font1=builtin:ripps2sleekcase          # Bold Case
```

[RIPgrid](https://github.com/akilluminati47/RIPPS2-themes) سراسر با آن‌ها چیده شده است. هر پوستهٔ دیگری از خانوادهٔ OPL می‌تواند فایل‌های TTF را مثل هر قلمی از پوشهٔ خودش به کار ببرد.

**در وب:**

```css
@font-face { font-family: "RIPPS2 Sleek"; font-weight: 400; src: url("RIPPS2Sleek-Regular.woff2") format("woff2"); }
@font-face { font-family: "RIPPS2 Sleek"; font-weight: 700; src: url("RIPPS2Sleek-Bold.woff2") format("woff2"); }
@font-face { font-family: "RIPPS2 Sleek Case"; font-weight: 700; src: url("RIPPS2Sleek-BoldCase.woff2") format("woff2"); }
```

**روی رایانه:** فایل‌های TTF را مثل همیشه نصب کنید. Regular و Bold یک خانواده‌اند، *RIPPS2 Sleek*؛ Bold Case خانوادهٔ جدایی است، *RIPPS2 Sleek Case* (Bold)، تا هرگز با هم تداخل نکنند.

## ساخت

هر نشانه مجموعه‌ای از خط‌های شکسته روی شبکه‌ای به بلندی شش واحد (بلندی حروف بزرگ) است؛ هر کدام خط می‌خورد و خط‌ها در یک دورگیر تمیز یکی می‌شوند. نقشه در [tools/make_sleek_font.py](tools/make_sleek_font.py) است (همان فایلی که RIPPS2 نسخه‌های خود را از آن می‌سازد)؛ [tools/build.py](tools/build.py) همه‌چیز این‌جا را از آن می‌سازد و به قلم‌ها نام‌ها و ضخامت‌هایی می‌دهد که برنامه‌های رومیزی و مرورگرها می‌خوانند (خود RIPPS2 فقط دورگیرها را می‌خواند).

```
pip install -r requirements.txt
python tools/build.py
```
