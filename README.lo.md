# RIPPS2 Sleek

[![License OFL](https://img.shields.io/badge/license-OFL--1.1-orange?style=flat-square)](LICENSE-OFL)
[![License MIT](https://img.shields.io/badge/tools-MIT-green?style=flat-square)](LICENSE-MIT)
[![Releases](https://img.shields.io/github/v/release/akilluminati47/RIPPS2-fonts?style=flat-square)](https://github.com/akilluminati47/RIPPS2-fonts/releases)
[![RIPPS2](https://img.shields.io/badge/made_for-RIPPS2-3c6ef0?style=flat-square)](https://github.com/akilluminati47/RIPPS2)

ຮູບແບບຕົວອັກສອນທີ່ແຕ້ມໃຫ້ [RIPPS2](https://github.com/akilluminati47/RIPPS2), ໜ້າໂປຣແກຣມສຳລັບ PS2: ເມນູ, ຄຳແນະນຳປຸ່ມ, ການຕັ້ງຄ່າ, ຄຳມຸມມອງທີ່ຕັ້ງຊື່ໃຫ້ແຕ່ລະລາຍການ, ແລະທຸກທີມທີ່ຢາກເບິ່ງຄືຂອງບ້ານ.

ຕົວອັກສອນເອົາຕົວໜັງສືຂອງໂລໂກ້ PS2 ເປັນແບບ: ເສັ້ນດຽວບາງ ແລະ ສະໝ່ຳສະເໝີ, ມຸມສີ່ຫຼ່ຽມ, ຕົວອັກສອນທີ່ສ້າງຈາກແທ່ງແນວນອນ ແລະ ແນວຕັ້ງເທິງຕາໜ່າງ, ແລະຮູບຊົງເປີດຂອງໂລໂກ້ເອງ (P ທີ່ບໍ່ມີກ້ານເທິງທ້ອງ, ເລກ 2 ແບບຊິກແຊັກ). ມັນແຄບ, ດັ່ງນັ້ນຄຳແນະນຳປຸ່ມທັງແຖວຈຶ່ງພໍດີຈໍ 640 ພິກເຊວ.

| ແບບ | ຄວາມໜາ | ຕົວໃຫຍ່/ນ້ອຍ | ໃນ RIPPS2 |
|---|---|---|---|
| **Regular** | ເສັ້ນບາງ | ຕົວໃຫຍ່ (ຕົວນ້ອຍແຕ້ມເປັນຕົວໃຫຍ່) | ຄຳແນະນຳ, ເມນູ, ການຕັ້ງຄ່າ, ຊື່ແຫຼ່ງ |
| **Bold** | ເສັ້ນໜາ | ຕົວໃຫຍ່ | ປ້າຍຂ້າງກລິບໃຫຍ່, ຄຳມຸມມອງ, ແຖວເວີຊັນ |
| **Bold Case** | ເສັ້ນໜາ | ຕົວນ້ອຍແທ້ | ຂໍ້ຄວາມທີ່ພິມ, ແປ້ນພິມເທິງຈໍ, ຄຳອະທິບາຍ |

## ຊຸດຕົວອັກສອນ

ລາຕິນພື້ນຖານ, Latin-1 ແລະ ລາຕິນຂະຫຍາຍ A/B: 337 ຈຸດລະຫັດໃນແຕ່ລະແບບ. ຕອນນີ້ຕົວອັກສອນທີ່ມີເຄື່ອງໝາຍແຕ້ມເປັນຕົວພື້ນຖານ. ລາຍການເຕັມ: [docs/charset.md](docs/charset.md).

ຈາກ [Releases](https://github.com/akilluminati47/RIPPS2-fonts/releases), ຫຼືໂດຍກົງຈາກຄັງນີ້:

## ການໃຊ້

**ໃນທີມຂອງ RIPPS2** ຟອນມີຢູ່ໃນ `RIPPS2.elf` ແລ້ວ; ພຽງແຕ່ໃສ່ຊື່ ບໍ່ຕ້ອງສົ່ງຫຍັງ:

```
default_font=builtin:ripps2sleek       # Regular
font3=builtin:ripps2sleekbold          # Bold
font1=builtin:ripps2sleekcase          # Bold Case
```

[RIPgrid](https://github.com/akilluminati47/RIPPS2-themes) ຈັດພິມດ້ວຍພວກມັນທັງໝົດ. ທີມອື່ນໃດໆໃນຕະກູນ OPL ສາມາດໃຊ້ໄຟລ໌ TTF ຈາກໂຟນເດີຂອງຕົນເອງຄືກັບຟອນໃດໆ.

**ໃນເວັບ:**

```css
@font-face { font-family: "RIPPS2 Sleek"; font-weight: 400; src: url("RIPPS2Sleek-Regular.woff2") format("woff2"); }
@font-face { font-family: "RIPPS2 Sleek"; font-weight: 700; src: url("RIPPS2Sleek-Bold.woff2") format("woff2"); }
@font-face { font-family: "RIPPS2 Sleek Case"; font-weight: 700; src: url("RIPPS2Sleek-BoldCase.woff2") format("woff2"); }
```

**ໃນ PC:** ຕິດຕັ້ງໄຟລ໌ TTF ຕາມປົກກະຕິ. Regular ແລະ Bold ເປັນຄອບຄົວດຽວ, *RIPPS2 Sleek*; Bold Case ເປັນຄອບຄົວແຍກ, *RIPPS2 Sleek Case* (Bold), ດັ່ງນັ້ນທັງສອງຈະບໍ່ຂັດກັນ.

## ການສ້າງ

ແຕ່ລະກລິບແມ່ນຊຸດເສັ້ນຫັກເທິງຕາໜ່າງສູງຫົກໜ່ວຍ (ຄວາມສູງຕົວໃຫຍ່); ແຕ່ລະເສັ້ນຖືກລາກ ແລະ ເສັ້ນທັງໝົດຖືກລວມເປັນເສັ້ນຂອບດຽວທີ່ສະອາດ. ແບບແຕ້ມຢູ່ໃນ [tools/make_sleek_font.py](tools/make_sleek_font.py) (ໄຟລ໌ດຽວກັນທີ່ RIPPS2 ສ້າງສຳເນົາຂອງມັນ); [tools/build.py](tools/build.py) ສ້າງທຸກຢ່າງຢູ່ນີ້ຈາກມັນ ແລະ ໃຫ້ຟອນມີຊື່ ແລະ ຄວາມໜາທີ່ໂປຣແກຣມ ແລະ ບຣາວເຊີອ່ານ (RIPPS2 ອ່ານແຕ່ເສັ້ນຂອບ).

```
pip install -r requirements.txt
python tools/build.py
```
