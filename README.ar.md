# RIPPS2 Sleek

[![License OFL](https://img.shields.io/badge/license-OFL--1.1-orange?style=flat-square)](LICENSE-OFL)
[![License MIT](https://img.shields.io/badge/tools-MIT-green?style=flat-square)](LICENSE-MIT)
[![Releases](https://img.shields.io/github/v/release/akilluminati47/RIPPS2-fonts?style=flat-square)](https://github.com/akilluminati47/RIPPS2-fonts/releases)
[![RIPPS2](https://img.shields.io/badge/made_for-RIPPS2-3c6ef0?style=flat-square)](https://github.com/akilluminati47/RIPPS2)

الخط المرسوم لـ [RIPPS2](https://github.com/akilluminati47/RIPPS2)، الواجهة الأمامية لجهاز PS2: قوائمه، وتلميحات الأزرار، والإعدادات، وكلمة العرض التي تسمّي كل قائمة، وكل سمة تريد أن تبدو من أهل البيت.

تتخذ الحروف كتابة شعار PS2 نموذجًا: خط واحد رفيع ومتساوٍ، وزوايا مربعة، وحروف مبنية من أشرطة أفقية وعمودية على شبكة، والأشكال المفتوحة للشعار نفسه (حرف P بلا ساق فوق بطنه، والرقم 2 المتعرج). وهي ضيقة، فيتسع صف كامل من تلميحات الأزرار لشاشة بعرض 640 بكسل.

| القطع | السماكة | حالة الأحرف | في RIPPS2 |
|---|---|---|---|
| **Regular** | خط رفيع | أحرف كبيرة (تُرسم الصغيرة كبيرة) | التلميحات، القوائم، الإعدادات، اسم المصدر |
| **Bold** | خط عريض | أحرف كبيرة | تسميات بجانب الرموز الكبيرة، كلمة العرض، سطر الإصدار |
| **Bold Case** | خط عريض | أحرف صغيرة حقيقية | النص المكتوب، لوحة المفاتيح على الشاشة، الأوصاف |

## الاستخدام

**في سمة لـ RIPPS2** الخطوط موجودة أصلًا داخل `RIPPS2.elf`؛ سمِّها ولا ترسل شيئًا:

```
default_font=builtin:ripps2sleek       # Regular
font3=builtin:ripps2sleekbold          # Bold
font1=builtin:ripps2sleekcase          # Bold Case
```

[RIPgrid](https://github.com/akilluminati47/RIPPS2-themes) مصفوف بها بالكامل. ويمكن لأي سمة أخرى من عائلة OPL أن تستخدم ملفات TTF من مجلدها الخاص كأي خط.

**على الويب:**

```css
@font-face { font-family: "RIPPS2 Sleek"; font-weight: 400; src: url("RIPPS2Sleek-Regular.woff2") format("woff2"); }
@font-face { font-family: "RIPPS2 Sleek"; font-weight: 700; src: url("RIPPS2Sleek-Bold.woff2") format("woff2"); }
@font-face { font-family: "RIPPS2 Sleek Case"; font-weight: 700; src: url("RIPPS2Sleek-BoldCase.woff2") format("woff2"); }
```

**على الحاسوب:** ثبّت ملفات TTF كالمعتاد. Regular وBold عائلة واحدة، *RIPPS2 Sleek*؛ أما Bold Case فعائلة مستقلة، *RIPPS2 Sleek Case* (Bold)، فلا تتصادمان أبدًا.

<a id="build"></a>

## البناء

كل رمز مجموعة من الخطوط المتكسرة على شبكة ارتفاعها ست وحدات (ارتفاع الأحرف الكبيرة)؛ يُرسم كل منها بخط وتُدمج الخطوط في محيط واحد نظيف. الرسم موجود في [tools/make_sleek_font.py](tools/make_sleek_font.py) (الملف نفسه الذي يبني منه RIPPS2 نسخه)؛ ويصنع [tools/build.py](tools/build.py) منه كل ما هنا، ويعطي الخطوط الأسماء والسماكات التي تقرؤها برامج سطح المكتب والمتصفحات (RIPPS2 نفسه لا يقرأ إلا المحيطات).

```
pip install -r requirements.txt
python tools/build.py
```
